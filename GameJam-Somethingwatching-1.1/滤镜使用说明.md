# 已接入 Looper CRT 滤镜

## 打开与查看

1. 解压后在 Unity Hub 添加 GameJam-Somethingwatching-CRT 文件夹。
2. 用源项目版本 Unity 6000.6.7f1 打开，等待依赖导入完成。请勿用 Unity 2022 打开这个项目。
3. 在 Project 中打开 Assets/YunYuanShen.unity，切到 Game 视图并点击 Play 查看游戏画面。
4. Assets/Scenes/SampleScene.unity 也会使用同一个滤镜配置，但它是源项目的另一个场景。

## 开关和调节

- 打开 Assets/Settings/Renderer2D.asset，在 Inspector 的 Renderer Features 中，开关 Looper CRT Filter 可对比原画。
- 选中 Assets/LooperCRTFilter/CRT Filter.mat，调整 Blur Offset（颜色偏移）、Scan Line Number（扫描线数量）、Scan Line Speed（扫描线速度）。
- 已使用 Looper 原始参数：0.002 / 200 / 0.01。
- 全屏通道设置：After Rendering Post Processing、Fetch Color Buffer 开启、Requirements None、Pass Index 0。
